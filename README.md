# N9.COM 前端项目

这是一个使用 Vue 2 + HTML5 + CSS3 开发的前端项目。

## 🚀 功能特性

- ✨ 响应式设计，完美适配手机
- 🌍 多语言支持（中文、英文、越南语）
- 🔐 用户登录/注册系统
- 💾 本地数据持久化
- 🎨 现代化 UI 设计
- ⚡ 快速加载，无需构建

## 📁 文件结构

```
N9/
├── index.html    # 主页面
├── app.js        # Vue 应用逻辑
└── README.md     # 项目说明
```

## 🎯 快速开始

### 方式 1：直接打开（最简单）

1. 下载 `index.html` 和 `app.js` 到本地
2. 用浏览器打开 `index.html`
3. 完成！

### 方式 2：GitHub Pages 部署

1. 访问 https://MinHao88.github.io/N9/
2. 即可在线使用

## 💡 使用说明

### 登录/注册

- 点击「首页」上的「登录」按钮
- 输入用户名和密码
- 支持注册新账户
- 数据会保存在本地浏览器（localStorage）

### 切换语言

- 点击右上角语言按钮
- 支持 中文 / English / Tiếng Việt

### 底部导航

- 🏠 首页 - 显示用户信息
- 🎁 活动 - 活动页面
- 👤 我的 - 个人资料

## 🛠️ 技术栈
